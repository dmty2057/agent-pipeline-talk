## Як показати

**Покроково у VS Code:** відкрити `NN-….steps.md` і натиснути `Ctrl+Shift+V` — таблиця кроків з часом.

**«Наживо» в терміналі, без мережі** (з реальними паузами; `-d 2` — удвічі швидше):

```bash
cd ~/Desktop/presentation/agent-pipeline-talk-wiki/runs/live-2026-10-07
scriptreplay -T 03-ask-mercury-A.timing 03-ask-mercury-A.terminal.txt
scriptreplay -T 04-ask-mercury-B.timing 04-ask-mercury-B.terminal.txt
```

Це програвання запису, а не новий запит: агент не запускається, модель не викликається.

Особисті поля (email, ID акаунта й організації, домашня тека) з усіх файлів прибрано. Звіт `/insights` — з нейтральними даними.

# Агентний пайплайн: від промпту до системи

Демо-проєкт і слайди доповіді Дмитра Тимочка.

Агент-«детектив» відповідає на питання за статтями **української Вікіпедії**, маючи два інструменти:
пошук статей і повний текст статті. Навколо нього зібрано весь цикл вимірювань:

```
промпт → інструменти → цикл → телеметрія (OpenTelemetry + Langfuse) → евали → порівняння версій
```

Головна думка доповіді: **між «начебто працює» і «працює» стоїть не краща модель, а звичка вимірювати.**
Найкраще це видно на порівнянні двох інструкцій: «покращена» версія B набирає 13/20 проти 15/20 і тихо
ламає справи, які раніше розкривались правильно.

## Запуск

Потрібно: **Node.js 20+** і доступ до Claude — встановлений і залогінений
[Claude Code](https://docs.claude.com/en/docs/claude-code) (`claude` → `/login`) або `ANTHROPIC_API_KEY`.

```bash
npm ci
cp .env.example .env        # вписати ключі Langfuse, якщо потрібна телеметрія
npm run ask -- "Яка висота Говерли?"
```

Перевірка і порівняння:

```bash
PROMPT_VERSION=v1 npm run eval    # → runs/v1.json, ~4 хв
PROMPT_VERSION=v2 npm run eval    # → runs/v2.json
npm run compare                   # таблиця v1 проти v2 і список регресій
```

Подивитися порівняння з доповіді, нічого не запускаючи:

```bash
cp runs/stage/v1.json runs/stage/v2.json runs/ && npm run compare
```

Один прогін перевірки коштує близько $1,5. Модель щоразу відповідає трохи інакше, тож ваші цифри можуть
відрізнятися від слайдів.

### Телеметрія

Безкоштовного тарифу [Langfuse](https://langfuse.com) достатньо. Ключі проєкту впишіть у `.env`, а для
`OTEL_EXPORTER_OTLP_HEADERS` закодуйте пару `public:secret` у base64:

```bash
printf '%s' 'pk-lf-...:sk-lf-...' | base64 -w0
```

Без ключів агент працює так само, просто наприкінці виведе `telemetry export failed: 401`.

## Що варто знати

- **Агент працює через Claude Agent SDK 0.1.x.** Вбудований у нього Claude Code не вкладає свої кадри під
  `TRACEPARENT` нашого кадру, тому `agent.run` і кадри Claude Code лежать в окремих трейсах. Їх об'єднує
  спільний `session.id`, тож у Langfuse один запуск — це одна сесія (**Sessions**).
- **Langfuse показує нові записи із затримкою** — на безкоштовному тарифі до ~6 хвилин.
- **`get_article` віддає лише перший абзац статті.** Цю ваду інструмента доповідь знаходить через телеметрію:
  агент так і не може знайти площу Києва. Вона лишилась як є; щоб полагодити, віддавайте ще й дані з картки статті.
- **Вікіпедія обмежує частоту запитів**, тому `src/tools/wiki.ts` чекає і повторює запит при відповіді 429.
